Edit every part of your site with simple boxes. No coding. The FAQ is kept as-is automatically.

How it works: Change any box below, click the big button at the bottom, and it downloads a finished file. Then upload that file to your GitHub repo (Add file → Upload files → Commit) and your live site updates in about a minute. For images, type the file name exactly as it appears in your images folder. Your entries are saved automatically — close this and reopen it later and everything you typed will still be here. Use Back up my content if you ever want to move it to another computer.
